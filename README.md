# https://bebradio.ru

listen together

Веб-приложение для совместного прослушивания музыки в реальном времени. Создавай комнаты, добавляй треки из YouTube, слушай с друзьями — все синхронизированы.

## Архитектура

Работа с YouTube и аудиофайлами вынесена в отдельный `media-service`. Основной backend отвечает за комнаты, очередь, авторизацию и синхронизацию, а media-service — за поиск, metadata, загрузку, captions и Range-раздачу аудио. Оба сервиса используют volume `mediadata`; в production `/api/media/*` проксируется напрямую в media-service.

Внутри media-service слои разделены по ответственности: `api.py` содержит HTTP-контракты, `service.py` координирует операции, `providers/youtube.py` изолирует `yt-dlp`, `storage.py` отвечает за файлы, locks, cleanup и лимиты диска, а `schemas.py` содержит входные модели.

Для локального запуска достаточно `docker compose up --build`. URL media-service настраивается через `MEDIA_SERVICE_URL`, а его хранилище и лимиты через `MEDIA_DIR`, `MEDIA_TTL`, `MEDIA_MAX_SIZE` и `MAX_DOWNLOADS`.

## Возможности

- **Комнаты** — создавай приватные или публичные комнаты, делись кодом с друзьями
- **Пароль на комнату** — защити комнату паролем: без него не попасть ни в плеер, ни в чат, ни в очередь (владелец заходит без пароля)
- **Удаление комнаты** — создатель может удалить комнату вместе с очередью и чатом; слушатели автоматически возвращаются на главную
- **Очередь треков** — добавляй YouTube треки по ссылке или через поиск
- **Синхронизация** — все слушатели видят один и тот же трек в одном темпе
- **Голосование** — лайки/дизлайки, автоматический пропуск при большинстве дизлайков
- **Пропуск** — голосование за пропуск трека (нужно >=50% слушателей)
- **Авто-переход** — сервер сам двигает очередь по окончании трека, даже если все клиенты отвалились
- **Живые ссылки** — просроченные YouTube-потоки автоматически перевыпускаются, треки в очереди не «умирают»
- **Авто-радио** — когда очередь заканчивается, комната сама подтягивает похожие треки из YouTube Mix (включается владельцем)
- **Кто слушает** — список участников комнаты в реальном времени
- **Эмодзи-реакции** — летящие реакции поверх плеера
- **Чат** — общение в реальном времени внутри комнаты
- **Тёмная тема** — автоматическое переключение или ручной выбор
- **Анонимное добавление** — настройка комнаты для добавления треков без авторизации

## Планы

- **Live Radio** — режим живого радио с разными жанрами. Например, мешап радио
- **Роли в комнатах** — DJ, модератор, слушатель с разными правами
- **Индикатор набора** — видно, когда кто-то печатает в чате
- **Статистика** — история прослушиваний, топ треков, активность пользователей
- **Публичные профили** — страницы пользователей с историей и избранным
- **Интеграция с Spotify** — импорт плейлистов и треков
- **Мультирум** — несколько комнат одновременно с переключение
